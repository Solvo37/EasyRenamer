# EasyRenamer

EasyRenamer — полностью бесплатная программа с открытым исходным кодом для массового переименования файлов в Windows. В проекте нет рекламы, подписки, телеметрии, платной редакции или искусственно урезанной бесплатной версии. Проект технический и вне политики.

> Проект находится в активной разработке. Базовый движок, предпросмотр, цепочки методов, откат последней операции и Windows-интерфейс уже работают.

## Принципы проекта

- **0 ₽ / $0 навсегда** — все функции доступны бесплатно.
- **Open source** — лицензия MIT.
- **Без рекламы и подписок**.
- **Без телеметрии** и скрытого сбора аналитики.
- **Один portable EXE** — установка не обязательна.
- **Вне политики** — EasyRenamer не связан с партиями, государствами или политическими движениями.

## Языки

Интерфейс поддерживает **English, Русский, Español и 中文**. Язык можно менять прямо во время работы через **Language / Язык / Idioma / 语言** — без перезапуска процесса. Тема по умолчанию следует настройке Windows; **System / Light / Dark** также переключаются сразу, при этом окно пересобирается внутри того же процесса и сохраняет текущую задачу. Тёмная тема использует более мягкую серую палитру без почти чёрного фона. Таблицы и системные выпадающие списки дополнительно темизируются через Win32, чтобы не оставлять белые области внутри dark mode.


## Возможности

- добавление отдельных файлов и нескольких папок в одну задачу, включая drag & drop из Проводника;
- заметная зона-подсказка для перетаскивания файлов и папок в пустой список;
- после drag & drop можно выбрать: файлы, папки или оба типа, а также включить/выключить подпапки и запомнить выбор;
- обработка вложенных папок;
- фильтры: все файлы, изображения, видео, аудио, документы, архивы и произвольные расширения;
- естественная сортировка имён: `1`, `2`, `10`, а не `1`, `10`, `2`;
- живой предпросмотр нового имени: изменения шаблона и настроек обновляют таблицу автоматически с небольшим debounce;
- предпросмотр можно отменить; устаревшие пересчёты отменяются автоматически, чтобы UI не зависал на тяжёлых папках;
- размер файла и размеры изображения (PNG/JPEG/GIF) прямо в таблице предпросмотра;
- галочки для исключения отдельных файлов из операции;
- несколько методов переименования, которые применяются сверху вниз;
- изменение порядка методов, временное отключение и дублирование;
- шаблоны нового имени с расширенной системой тегов, fallback и модификаторами;
- теги дат, размеров, MD5/SHA1 и распространённых метаданных EXIF/GPS, аудио, видео, документов и Windows EXE;
- поиск и замена, в том числе по регулярным выражениям;
- добавление префикса и суффикса;
- изменение регистра;
- удаление символов по позиции и удаление текста/regex-паттернов;
- перенос фрагмента имени на другую позицию;
- отдельный Renumber со стартом, шагом, padding и нумерацией по папкам;
- Trim с нормализацией пробелов;
- Timestamp по времени изменения файла или времени batch;
- List для ручного списка новых имён и импорта TXT/CSV;
- List Replace для нескольких пар замены в одном методе;
- Swap для перестановки двух частей имени по разделителю;
- Script expression для вычисляемого имени с переменными и функциями;
- сохранение и загрузка наборов методов в JSON;
- проверка конфликтов и недопустимых имён Windows;
- двухэтапное транзакционное переименование для защиты от коллизий;
- отмена последней операции;
- светлая, тёмная и системная тема интерфейса; тёмная палитра построена на нейтральных графитовых поверхностях в духе современных desktop-приложений;
- один переносимый `.exe` без установщика.

## Интерфейс

В v0.5 рабочее окно было перестроено вокруг схемы профессиональных пакетных переименователей: слева — цепочка методов и настройки выбранного метода, справа — большой список файлов и предпросмотр. В v0.5.2 левая колонка стала плоской и компактной: меньше рамок, отдельные заголовки секций и один селектор **Добавить метод** вместо сетки из множества кнопок. Размер первого окна автоматически подбирается под рабочую область Windows и DPI; левая колонка прокручивается на небольших экранах.

1. Добавьте файлы и/или папки кнопками **Files** и **Folder**. Отдельный переключатель Batch mode убран: сейчас EasyRenamer поддерживает один фактический режим — безопасное переименование.
2. Слева соберите список **Renaming methods** — это единственное место, где методы добавляются, удаляются и задаётся их порядок. Для добавления используется компактный выпадающий список метода и кнопка **Добавить**.
3. Выберите метод слева. Его настройки открываются **сразу под списком методов в левой рабочей колонке**. Правая часть окна отдана списку файлов и предпросмотру.
4. Проверьте колонки **Filename** и **New filename**.
5. Снимите галочки с файлов, которые не нужно менять.
6. Нажмите **Start batch**.

Методы можно переставлять кнопками **Up / Down** или перетаскиванием мышью, дублировать через **Copy** и временно отключать чекбоксом. Поле **Extensions** всегда доступно: ввод расширений автоматически выбирает пользовательский фильтр. Набор методов можно сохранить в JSON и затем загрузить обратно. Результат одного активного метода становится входом для следующего. При включённом **Live preview** изменения в `New Name`, Replace, Prefix/Suffix и других настройках автоматически пересчитывают колонку **New filename**. Названия встроенных пресетов локализованы вместе с интерфейсом. В `New Name` вместо сырого выпадающего списка используется вкладочный справочник тегов: рядом с каждым тегом показывается перевод и понятное описание на выбранном языке; двойной клик вставляет тег в позицию курсора.

## Методы переименования

### New Name

Создаёт имя по шаблону. Например:

```text
<Inc NrDir:01>-<Name>
```

Результат:

```text
01-photo.jpg
02-photo.jpg
03-photo.jpg
```

### Replace

Поиск и замена текста в имени. При необходимости можно включить регулярные выражения.

### Add text

Добавляет префикс и/или суффикс к имени файла.

### Change case

Переводит основную часть имени в:

- `lower case`;
- `UPPER CASE`;
- `Title Case`.

### List

Назначает новое имя каждому элементу по строкам: первая строка — первому файлу, вторая — второму и т. д. Можно заполнить список текущими именами, загрузить TXT/CSV и сохранить список обратно.

### List Replace

Позволяет выполнить много замен за один метод. В текстовом поле каждая строка задаётся как:

```text
find => replace
```

Также поддерживаются tab-separated пары, регулярные выражения и режим с учётом регистра.


### Move

Переносит фрагмент имени: задаются начальная позиция, количество символов и новая позиция.

### Remove

Удаляет заданное количество символов, начиная с указанной позиции.

### Remove pattern

Удаляет обычный текст либо все совпадения регулярного выражения.

### Renumber

Добавляет номер как префикс или суффикс. Настраиваются старт, шаг, количество цифр, разделитель и перезапуск счётчика внутри каждой папки.

### Trim

Убирает пробелы по краям имени и, при необходимости, схлопывает повторяющиеся пробелы внутри имени.

### Timestamp

Добавляет дату и время из `Modified time` файла или из времени текущего batch. Поддерживает prefix/suffix и формат вроде `yyyyMMdd-HHmmss`.

### Swap

Меняет местами две части имени, разделённые заданной строкой. Можно выбрать occurrence разделителя, если он встречается несколько раз.

### Script

Выполняет безопасное выражение для каждого файла. Это не произвольный JavaScript: выражение не имеет доступа к файловой системе или сети.

Доступные переменные: `Name`, `Ext`, `FullName`, `Index`, `DirIndex`, `DirName`, `UnixTimestamp`, `ModifiedUnix`.

Доступные функции: `lower()`, `upper()`, `trim()`, `replace()`, `concat()`, `substr()`.

Например:

```text
concat(lower(Name), "-", Index, Ext)
```

## Токены шаблонов

| Токен | Значение |
| --- | --- |
| `<Name>` | текущее имя без расширения |
| `<Ext>` | расширение без точки |
| `<Inc:001>` | общий счётчик (`001`, `002`, ...) |
| `<Inc NrDir:01>` | счётчик, который начинается заново в каждой папке |
| `<DirName:1>` | имя родительской папки |
| `<UnixTimestamp>` | Unix timestamp текущего предпросмотра |
| `<Rand>` | одна случайная цифра |
| `<Rand Str:8>` | случайная строка из букв и цифр |
| `<Rand Alpha:9>` | случайная строка только из букв |
| `<Date:yyyyMMdd-HHmmss>` | дата и время |

Полный современный справочник: [docs/TAGS.md](docs/TAGS.md). Старый краткий справочник: [docs/TOKENS.md](docs/TOKENS.md).

## Безопасность переименования

EasyRenamer сначала строит полный план операции и только потом меняет файлы:

1. собирает и сортирует список;
2. применяет методы и строит новые имена;
3. проверяет недопустимые символы и конфликты;
4. временно переименовывает выбранные файлы в уникальные служебные имена;
5. переводит их в конечные имена;
6. при ошибке пытается вернуть уже изменённые файлы обратно;
7. сохраняет успешную операцию для **Undo batch**.

## Сборка из исходников

Требования:

- Go 1.23+;
- Windows для сборки графического интерфейса.

```powershell
git clone https://github.com/Solvo37/easyrenamer.git
cd easyrenamer
go test ./internal/...
go build -trimpath -ldflags "-H windowsgui" -o EasyRenamer.exe ./cmd/easyrenamer
```

GitHub Actions автоматически проверяет движок, собирает portable Windows EXE и публикует релизные артефакты.
