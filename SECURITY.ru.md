# Безопасность

<p align="center"><a href="SECURITY.md">English</a> · <strong>Русский</strong> · <a href="SECURITY.es.md">Español</a> · <a href="SECURITY.zh-CN.md">中文</a></p>

EasyRenamer выполняет файловые операции, поэтому ошибки, способные повредить пользовательские данные, считаются критичными.

## Сообщить о проблеме

Обычные баги можно создавать через GitHub Issues.

Если проблема может неожиданно перезаписать, потерять, повредить или раскрыть файлы пользователя, описывайте её на временных тестовых данных и не публикуйте приватные файлы, пароли, персональные пути или другую чувствительную информацию.

## Принципы безопасности

- destructive overwrite отключён, пока нет безопасного backup/restore;
- план rename валидируется до выполнения;
- используются уникальные временные имена для защиты от внутренних коллизий;
- успешные операции по возможности записываются в журнал для Undo.

Исправление не должно ослаблять эти гарантии только ради того, чтобы операция «прошла».
