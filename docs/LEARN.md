# Learn — EasyRenamer

Это практическое руководство по текущей версии EasyRenamer. Проект развивается как полностью бесплатный и открытый пакетный переименователь без рекламы, подписки, телеметрии и платных функций.

## Быстрый старт

1. Добавьте файлы или папки кнопками **Files / Folders** либо перетащите их из Проводника.
2. Слева добавьте один или несколько методов переименования.
3. Методы выполняются сверху вниз. Их можно отключать галочкой, копировать и менять порядок перетаскиванием.
4. Проверьте **New filename** и колонку ошибок.
5. Снимите галочки с элементов, которые не нужно менять.
6. Нажмите **Start batch**.
7. Последний успешный пакет можно вернуть через **Undo batch**.

## Renaming methods

Цепочка методов — основа EasyRenamer. Каждый активный метод получает имя, созданное предыдущим методом.

### Add method

В блоке **Add batch method** выберите нужный метод. Выбранный метод появится в списке слева и сразу станет доступен для настройки.

### List method

Назначает имена построчно: первая строка относится к первому элементу, вторая — ко второму и т. д.

Доступно:

- **Populate list** — заполнить текущими именами;
- загрузка TXT/CSV;
- сохранение списка;
- режим, в котором строка уже содержит расширение.

### List replace method

Позволяет выполнить несколько замен одним методом.

```text
старое => новое
red => green
draft => final
```

Можно использовать tab-separated пары, регулярные выражения и режим с учётом регистра.

### Move method

Переносит фрагмент имени. Настраиваются:

- начальная позиция;
- количество символов;
- новая позиция.

Позиции считаются по имени без расширения.

### New case method

Меняет регистр имени:

- lower case;
- UPPER CASE;
- Title Case.

### New name method

Создаёт имя по шаблону из текста и тегов.

```text
<Inc NrDir:01>-<Name>-<Date Modified:yyyy-mm-dd>
```

Полный справочник: [TAGS.md](TAGS.md).

### Remove method

Удаляет N символов начиная с заданной позиции.

### Remove pattern method

Удаляет обычный текст либо совпадения регулярного выражения.

### Renumber method

Добавляет номер в начало или конец имени. Доступны:

- Start;
- Step;
- Padding;
- Prefix / Suffix;
- Separator;
- отдельный счётчик в каждой папке.

### Replace method

Обычный поиск и замена. Можно включить регулярные выражения.

### Add text method

Добавляет префикс и/или суффикс, сохраняя расширение.

### Script method

Выполняет безопасное выражение над именем файла. Это не произвольный JavaScript: выражение не получает прямого доступа к файловой системе или сети.

Переменные:

`Name`, `Ext`, `FullName`, `Index`, `DirIndex`, `DirName`, `UnixTimestamp`, `ModifiedUnix`.

Функции:

`lower()`, `upper()`, `trim()`, `replace()`, `concat()`, `substr()`.

Пример:

```text
concat(lower(Name), "-", Index, Ext)
```

### Swap method

Меняет местами две части имени, разделённые выбранной строкой.

```text
Michael Jackson - Thriller
Thriller - Michael Jackson
```

### Timestamp method

Добавляет дату/время изменения файла или время текущего batch. Можно выбрать формат, разделитель и позицию.

### Trim method

Удаляет пробелы по краям имени и при необходимости схлопывает повторяющиеся пробелы внутри.

## Batch method conditions

Условия выполнения отдельных методов пока не реализованы. Это отдельный пункт roadmap. До их появления можно:

- отключать методы галочкой;
- исключать отдельные файлы из batch;
- использовать regex для более точной обработки.

## Batch modes

Сейчас основной и безопасный режим — **Rename**: файл остаётся в своей папке и получает новое имя.

Отдельные режимы Move/Copy на уровне всего batch пока не добавлены. Метод **Move** в списке методов означает перенос символов внутри имени, а не перемещение файла между папками.

## Command line

Полноценный стабильный CLI-интерфейс пока не опубликован. Движок отделён от GUI, поэтому CLI можно добавить без переписывания логики переименования.

Для автоматизации сейчас рекомендуется сохранять **method set JSON**, чтобы наборы методов можно было воспроизводить.

## ExifTool

EasyRenamer не поставляет внешний ExifTool и не требует его для основных метаданных.

Внутри portable EXE уже есть собственные читатели для распространённых данных:

- EXIF/GPS JPEG/TIFF;
- MP3 ID3 и FLAC Vorbis comments;
- MP4/MOV;
- PDF, Office Open XML, EPUB, EML;
- Windows EXE version resources.

Это сохраняет принцип одного переносимого EXE. Универсальная поддержка всех произвольных ExifTool-полей пока не заявляется.

## File pairs

Автоматическое связывание пар файлов пока не реализовано. Это актуально, например, для RAW+JPEG или видео+subtitle и остаётся отдельной задачей.

## Shortcuts

Специальная карта горячих клавиш пока минимальна. Работают стандартные клавиши Windows в полях ввода. Отдельные shortcut-команды для запуска batch, undo и управления методами находятся в roadmap.

## Name collision rules

EasyRenamer по умолчанию использует безопасное правило **Prevent overwrite**.

До выполнения batch проверяются:

- одинаковые конечные имена;
- уже существующий файл назначения;
- запрещённые Windows-символы;
- зарезервированные имена Windows;
- пустые или некорректные имена.

Само переименование выполняется в две фазы через уникальные временные имена, чтобы избежать внутренних коллизий.

## Regular expressions

Regex поддерживаются в:

- Replace;
- Remove pattern;
- List Replace.

Используется регулярный синтаксис Go RE2. Он не допускает конструкции, способные вызвать катастрофический backtracking.

## The item list

Основная таблица показывает:

- исходное имя;
- новое имя;
- путь;
- размер;
- Width / Height для поддерживаемых изображений;
- ошибку/статус.

Каждый файл можно включать и исключать галочкой. Двойной клик открывает его расположение в Проводнике.

## Undo batch

После успешного переименования EasyRenamer сохраняет последнюю транзакцию. **Undo batch** пытается вернуть все файлы к предыдущим именам.

Undo требует, чтобы после batch файлы оставались доступными по ожидаемым путям и чтобы исходные имена не были заняты другими файлами.

## Tags

Теги охватывают счётчики, папки, даты, размеры, контрольные суммы и распространённые метаданные изображения, аудио, видео, документов, GPS и Windows EXE.

См. [TAGS.md](TAGS.md).

## Languages

Основной интерфейс поддерживает:

- English;
- Русский;
- Español;
- 中文.

Язык определяется по Windows при первом запуске. Его можно изменить через меню **Language**; настройка сохраняется для следующих запусков.
