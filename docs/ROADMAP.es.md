# Roadmap de EasyRenamer

<p align="center"><a href="ROADMAP.md">English</a> · <a href="ROADMAP.ru.md">Русский</a> · <strong>Español</strong> · <a href="ROADMAP.zh-CN.md">中文</a></p>

Este roadmap refleja el estado del proyecto después de **v1.0.x**. No se prometen fechas: la estabilidad y la seguridad de archivos tienen prioridad.

## ✅ v1.0 — publicado

Ya están listos el UI Wails + React, varias carpetas por tarea, drag & drop, agrupación, orden natural y explícito, numeración por carpeta, cadenas de métodos, preview automático, validación, rename en dos fases, progreso/cancelación, Undo e historial, búsqueda, autocomplete, menús contextuales, shortcuts, columnas configurables, presets, virtualización y UI EN/RU/ES/ZH.

## v1.1 — fiabilidad y paridad

Prioridades:

- Timestamp real del sistema de archivos;
- condiciones por método;
- Apply To para nombre / extensión / ambos;
- Renumber avanzado sobre números existentes;
- Remove y Change Case más completos;
- import/export de listas;
- importación CSV y etiquetas CSV;
- renombrado de carpetas;
- modos Copy / Move seguros;
- file pairs;
- resumen detallado del resultado;
- persistencia de geometría de ventana;
- accesibilidad y focus states.

## v1.2 — funciones avanzadas

- panel de detalles y descubrimiento de etiquetas;
- más lectores nativos de metadatos;
- integración opcional con ExifTool;
- Script más potente;
- CLI;
- exportación TXT / CSV / JSON / HTML;
- reglas de colisión avanzadas;
- perfiles completos e import/export de presets;
- más reglas de orden y filtro.

## Más adelante

Metadata writer, reverse geocoding GPS opcional, binarios firmados y posible soporte macOS.

## No objetivos

No convertir EasyRenamer en gestor de archivos, servicio cloud, producto con cuentas, suscripción, publicidad o telemetría invasiva.
