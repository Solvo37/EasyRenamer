# EasyRenamer Roadmap

<p align="center"><a href="ROADMAP.md">English</a> · <a href="ROADMAP.ru.md">Русский</a> · <a href="ROADMAP.es.md">Español</a> · <strong>中文</strong></p>

本路线图反映 **v1.0.x** 之后的项目状态。不会承诺具体日期；稳定性和文件安全优先于进度表。

## ✅ v1.0 — 已发布

已完成：Wails + React UI、多文件夹任务、拖放、文件夹分组、自然排序和显式处理顺序、按文件夹编号、方法链、自动预览、冲突与 Windows 名称校验、安全两阶段重命名、进度/取消、Undo 与历史记录、搜索、标签自动补全、右键菜单、快捷键、可配置列、用户预设、表格虚拟化、EN/RU/ES/ZH 界面。

## v1.1 — 可靠性与功能对齐

优先项：

- 真正修改 Created / Modified / Accessed 的 Timestamp；
- 每个方法的条件；
- Name / Extension / Both 的 Apply To；
- 在所有兼容的方法字段中使用标签；
- 对现有数字进行更强的 Renumber；
- 更完整的 Remove 与 Change Case；
- 列表导入/导出和单项新名称 override；
- 按条件 mark/unmark/remove；
- CSV 数据导入和 CSV 标签；
- 文件夹重命名；
- 安全 Copy / Move 模式；
- file pairs；
- 更详细的操作结果；
- 保存完整窗口几何状态；
- 无障碍和焦点状态。

## v1.2 — 高级功能

- 元数据详情、标签发现和收藏标签；
- thumbnail grid 模式；
- 更多原生 metadata reader；
- 可选 ExifTool 集成；
- 更强的 Script；
- CLI 自动化；
- TXT / CSV / JSON / HTML 导出；
- 高级冲突策略；
- 完整操作配置文件和 preset 导入/导出；
- 更多排序与筛选规则。

## 以后

Metadata writer、可选 GPS reverse geocoding、Windows 签名以及可能的 macOS 支持。

## 非目标

EasyRenamer 不计划成为文件管理器、云服务、账号产品、订阅产品、广告平台或重遥测应用。
